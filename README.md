# The Essence of Data Visualisation

Workshop material for PyCon Africa 2026.

Every plot and every table is a mapping from data to visual properties.
This workshop teaches that single idea using [plotnine](https://plotnine.org/) for plots and [great-tables](https://posit-dev.github.io/great-tables/) for tables,
through a case study of the Uganda 2024 Census.

## Setup

```bash
uv sync
```

## Build

```bash
uv run quarto preview
```
