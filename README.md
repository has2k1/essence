# The Essence of Data Visualisation

Workshop material for PyCon Africa 2026.

Learn how position, colour, size and text show data. Build plots with
[plotnine](https://plotnine.org/) and tables with
[great-tables](https://posit-dev.github.io/great-tables/), then use Uganda
census figures to find errors that are hard to spot in a plain table.

## Setup

Install the project dependencies:

```bash
uv sync
```

## Preview

Open a local preview of the workshop:

```bash
uv run quarto preview
```
